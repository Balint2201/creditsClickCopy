# Credits Click Copy

A small Spicetify extension that lets you copy Credits names with a single click.

## Features
- Click any artist / writer / producer name
- Instantly copies to clipboard
- No text selection needed
- Works around Spotify selection restrictions

## Usage
Open a track → View Credits → click a name to copy it.
Hold either Shift key to restore normal Spotify behaviour:
- Cursor switches back to pointer
- Our click handler is disabled so links and UI work normally

Tip: press and hold Shift before clicking. If a click starts while Shift is not yet held, Spotify may not treat it as a "modified" click.
